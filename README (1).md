# مطعم الزعفران — واجهتان فاخرتان
- `index.html` التصميم الأول: **الزعفران** (عاجي + زمردي + ذهبي)
- `theme-rose.html` التصميم الثاني: **روزا** (لؤلؤي + مرجاني + بنفسجي ناعم)
- `assets/app.js` القائمة والسلة والإرسال بواتساب (عدّل `WA` و`ITEMS`)

## الرفع على GitHub Pages
```
git init && git add . && git commit -m "restaurant ui"
git branch -M main && git remote add origin https://github.com/USER/REPO.git && git push -u origin main
```
ثم Settings ← Pages ← Branch: main ← Save.
